# DMX pagamentos

Dashboard de pagamentos em aberto da DMX Trading.

## Conteúdo

O arquivo `DashboardDMX.html` é um dashboard estático que pode ser aberto diretamente no navegador. Ele permite importar uma planilha de pagamentos, filtrar os lançamentos e visualizar os processos.

## Uso

Abra o arquivo `DashboardDMX.html` no navegador. Para carregar novas informações, utilize a opção de importação disponível no próprio dashboard.
